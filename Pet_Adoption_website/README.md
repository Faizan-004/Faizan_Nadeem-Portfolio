Link to Project: https://github.com/Faizan-004/Project-Website

Group Project from CSE2102 @ UConn

Goal: Create a full-stack website 
  Methods:
  - Frontend: React, TypeScript, Node.js, Vite, CSS, 
  - Backend: Python, Flask
  - Database: SQLite
  - Creation: Docker, GitHub actions

Success Criteria:
  - Users can select pets to adopt
  - Users must submit an application to be a approved to adopt
  - Notifications must be visible to users
  - Bookmarks can save/unsave pets from a list
  - Once adopted the pet is taken off the website
  - Admin's can approve/deny applications
  - Admins can add new pets
  - Login system must be functional
