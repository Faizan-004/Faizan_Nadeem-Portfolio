Stock Analysis Dashboard

A webapp created with Streamlit using Python, Yfinance, and pandas to deliver in-depth analytics to the user.
- for the purposes of this being a work in progress, only one stock can be analyzed at a time.


Input: User inputs the time period they held a stock for (current day is used if still held)

Output: Alpha, Beta, Risk-adjusted metics, drawdown, ...
  - All will be visible on the dashboard and when interacted with, will give the user more information.
